# Vibration Anomaly Detection

Exploratory Python experiments on vibration-spectrum data and anomaly detection, assembled as an academic portfolio.

## Source scripts
- `scripts/stat.py` — vibration statistics, visualization, and exploratory modeling
- `scripts/cleaning_data_2.py` — outlier handling and regression experiments
- `scripts/final_isof_lof_ee.py` — Isolation Forest, Local Outlier Factor, and Elliptic Envelope
- `scripts/anomali.py` — autoencoder and GAN experiments

## Libraries
Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn, and TensorFlow/Keras.

## Notes
These are original exploratory scripts **as provided**, not a tested end-to-end package. Some contain Google Colab-specific commands, rely on external CSV inputs, and may require adjustments before they run. No source datasets are uploaded.

**Authorship notice:** Attribution and permissions for any third-party or collaborative portions of the experiments are still being reviewed. Do not interpret the presence of a script as a claim that every line was authored by the repository owner.

**Confidentiality:** No original workplace data should be committed.
