# Vibration Anomaly Detection

Exploratory machine-learning research on vibration measurements and potential anomalous operating patterns.

## Methods explored
- Vibration-spectrum preprocessing and visualization
- Isolation Forest
- Local Outlier Factor (LOF)
- Elliptic Envelope
- Autoencoder-based anomaly analysis
- Generative adversarial network (GAN) experiments

## Technologies
Python, pandas, NumPy, scikit-learn, TensorFlow/Keras, matplotlib and Jupyter notebooks.

## Repository status
**Documentation only — source files are temporarily withheld.** The original experimental scripts need authorship, licensing, and confidentiality review before publication. Some work may involve code from other contributors and will be attributed accordingly.

## Reproducibility
Results and model effectiveness have not been independently verified. The original experiments depend on external data and environment-specific setup; no datasets or performance claims are published here.

## Purpose
Academic portfolio project focused on data analysis and experimental methods for learning from vibration measurements.
